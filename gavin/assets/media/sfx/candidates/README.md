# Distant artillery SFX candidates

All sourced from Freesound.org previews (`-hq.mp3`, no login required). Licences verified on
each sound's page. None are synthesized from scratch — all are real recordings (field
recordings, or recordings of real cannons/fireworks/explosions that were only trimmed, mixed,
filtered or pitch/time processed, not built from synth oscillators).

For each candidate: `candN_<slug>.mp3` is the original preview download (kept as downloaded).
`candN_hit.wav` is a trimmed single boom + natural rumble tail (48 kHz, peak-normalized to
-3 dBFS). `candN_barrage.wav` (where present) is a 6-8 s excerpt of a continuous barrage.
